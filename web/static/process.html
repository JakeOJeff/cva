Why this page is local-only

The public demo is a static site. Its pages are built from JSON that is committed to the repo, and there is no server behind them. Transcribing is the part that needs real hardware, so it happens here instead, on whatever machine is serving this page.

Hosting it properly was the first plan. Render's free tier gives you 512 MB of RAM, and the pipeline sits at roughly 726 MB before it has even opened an audio file, so the first stage was killed every time. Their paid CPU tiers are shared vCPU, which is the wrong shape for a job that runs flat out for tens of minutes rather than milliseconds.

There was no VPS to move it to either. That matters less than it sounds: on CPU, most tiers you would actually pay for are slower than a normal laptop, so hosting the server would have bought availability rather than speed.

Cloud compute is still the upgrade when it is worth it, and it does not need a rewrite. The same container on a rented GPU box, or in Colab, takes a 97 minute lesson down to a few minutes. Build it with --build-arg TORCH_INDEX=.../whl/cu124 and the pipeline finds CUDA by itself.
